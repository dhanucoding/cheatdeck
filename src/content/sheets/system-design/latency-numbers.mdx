## Latency
| Operation | Time |
|---|---|
| L1 cache reference | 1 ns |
| Mutex lock/unlock | 25 ns |
| Main memory reference | 100 ns |
| Compress 1 KB | 2 µs |
| Send 1 KB over 1 Gbps | 10 µs |
| SSD random read | 100 µs |
| Same-datacenter round trip | 0.5 ms |
| Read 1 MB from SSD | 1 ms |
| Disk seek (HDD) | 10 ms |
| Cross-continent round trip | 100-150 ms |

Takeaway: memory is ~1000x faster than SSD and ~100,000x faster than a network hop across regions.

## Handy estimates
| Fact | Value |
|---|---|
| Seconds per day | ~86,400 (call it 10^5) |
| 1M requests/day | ~12 requests/sec |
| 100M requests/day | ~1,200 requests/sec |
| 1 char | 1 byte (ASCII) |
| 1 million users x 1 KB | 1 GB |
